# Источник и методика

- Первичный источник: Букварикс, пользовательская CSV-выгрузка.
- В исходной выгрузке: 17 591 запрос.
- В этой выборке: 300 уникальных по точному тексту запросов; темы максимально разнообразны.
- Тексты запросов взяты из выгрузки и не генерировались ИИ.
- Частотность сохранена из выгрузки, **не измерена повторно и не гарантирует текущие показатели**.
- Это удобная тестовая подборка, не статистически репрезентативный срез всего поиска.
- Полная выгрузка Букварикса в репозиторий не включена.

Источник: https://www.bukvarix.com/
