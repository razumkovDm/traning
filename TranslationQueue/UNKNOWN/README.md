# UNKNOWN — очередь подготовки к переводу

Все запросы отобраны из реальной выгрузки Букварикса (`Processed/UNKNOWN.csv`), все 900 фраз являются исходными русскоязычными формулировками / клавиатурными шаблонами с подтверждённой частотностью.

## Структура

- `original_900.csv` — 900 отобранных оригинальных запросов класса UNKNOWN.
- `cleaned_900.csv` — очищенный набор 900 запросов.
- `keep_ru_300.csv` — 300 русских запросов (остаются без изменений).
- `translate_uk_300.csv` — 300 запросов для перевода на украинский язык.
- `translate_en_300.csv` — 300 запросов для перевода на английский язык.

## Состав по категориям (в каждой выборке из 300 строк)

- `cyrillic_mash`: 80 (кириллические клавиатурные паттерны: фывфыв, йцукен, ываыва, пролд...)
- `latin_mash`: 58 (латинские клавиатурные паттерны: asdf, qwertyuiop, zxcvbnm...)
- `hex_color`: 10 (цветовые коды и HEX: 000000 цвет, color 000000, hex 000000...)
- `mixed_or_other`: 92 (смешанные запросы, раскладки клавиатур, проценты, коды ошибок...)
- `currency`: 60 (числовые / валютные запросы с шаблоном нулей: 1 000000 юаней в рублях...)

Все 900 запросов имеют ненулевую подтверждённую частотность в Буквариксе (`fe > 0`).
