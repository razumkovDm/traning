# LOCAL — очередь подготовки к переводу

Все запросы взяты из исходного Букварикса, в файлах **везде исходный русский текст**. Никаких переводов нет.

## Файлы

- `original_900.csv` — неизменная копия `Processed/LOCAL_900_ru.csv`. Не редактировать.
- `cleaned_900.csv` — повторно очищенные 900 оригинальных русскоязычных LOCAL-запросов.
- `translation_plan.csv` — назначение языка каждой фразы, подтверждение происхождения, категория, исходная частотность и номер строки.
- `keep_ru_300.csv` — 300 русских запросов оставить без изменения.
- `translate_uk_300.csv` — 300 **русских** запросов на перевод **на украинский**.
- `translate_en_300.csv` — 300 **русских** запросов на перевод **на английский**.
- `review_log.csv` — все изменения относительно первоначального набора, с источниками и причинами.
- `QA_REPORT.md` и `qa_stats.json` — проверки и ограничения.

## Инструкция Antigravity

1. В `keep_ru_300.csv` запросы **не переводить**.
2. Для `translate_uk_300.csv` и `translate_en_300.csv` перевести поле `text` на язык назначения, сохранив поисковое намерение **LOCAL**.
3. После перевода установить `language=uk` или `language=en`, соответственно. Оставить `class_example=LOCAL`.
4. **Не переводить названия городов, брендов, официальные имена объектов и номера маршрутов** дословно, если это искажает их идентичность. Использовать стандартную транслитерацию/общепринятые названия. Пример: `РЖД` остаётся названием организации, а не калькой.
5. Если вопрос о конкретном российском госучреждении/адресе неестественен для другой языковой среды, не выдумывать зарубежный аналог. Пометить `REVIEW_NEEDED` и оставить исходник для ручной ревизии.
6. Строго сохранять 300 запросов в каждой группе, не объединять и не дублировать ID.
7. Для итогового датасета объединить русскую группу с результатами украинского и английского перевода. Проверить общий объём 900 и уникальность по паре `(text, language)`.

Резервные копии исходных CSV хранятся в ChatGPT Library `/pgF-traning-source-backup/2026-11-03/`. Другие классы и исходный `Processed/LOCAL_900_ru.csv` не изменялись.
