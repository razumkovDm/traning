# Шаблоны для Букварикса

В этом каталоге содержатся **153 поисковые маски** в 10 группах по намерению пользователя. Маски **не являются реальными поисковыми запросами** и предназначены для поиска реальных фраз в базе Букварикса.

Списки по категориям загружайте в https://www.bukvarix.com/mkeywords/ по одной строке на маску, экспортируйте результаты и проверяйте соответствие запросов типу намерения. Одно выражение может подходить нескольким категориям.

Операторы масок (`!`, `+`) сверяйте с текущими правилами Букварикса.
