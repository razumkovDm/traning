# Шаблоны для Букварикса

Всего **227 поисковых масок** в 12 наборах. Содержимое файлов — поисковые *маски*, а не подтверждённые запросы пользователей. Только найденные в базе Букварикса строки могут считаться запросами из этого источника.

## Как использовать

1. Откройте https://www.bukvarix.com/mkeywords/.
2. Вставьте маски нужного набора: одна строка = один поисковый шаблон.
3. Выгрузите найденные реальные запросы.
4. Удалите дубли и классифицируйте вручную либо по валидированным правилам.

Синтаксис Букварикса: https://www.bukvarix.com/query_syntax.html. Запросы могут содержать несколько обязательных слов; `(слово1|слово2)` означает выбор одного слова из группы, но **внутри скобок нельзя объединять несколько слов в одну альтернативу**.

## 11. MIXED

Файл: `11_mixed.txt` (48 масок). В каждой маске сочетаются сигналы двух разных намерений, например «сравнить + купить» либо «как сделать + стоимость».

**Проверка:** класс MIXED ставится, только если весь найденный запрос содержит **два самостоятельных намерения**. Слова «обзор» и «цена» сами по себе не гарантируют класс. Если одна часть — лишь уточнение другой, возможен единственный класс, например COMMERCIAL.

В примере пользователя: «ноутбук для учебы какой выбрать и где купить» — MIXED (выбор + покупка).

## 12. UNKNOWN

Файл: `12_unknown_candidates.txt` (26 масок). Это *затравки для поиска*, в основном последовательности клавиш и повторения символов.

**Ограничение:** для UNKNOWN не существует универсальной положительной маски: отсутствует понятное намерение, а не присутствует особое слово. Даже результаты поиска по `qwerty` могут оказаться нормальными информативными запросами о раскладке клавиатуры.

Лучший способ набрать реальные UNKNOWN-примеры:
1. Взять **общую реальную выгрузку**, не придумывая новые строки.
2. Отфильтровать короткие (1–2 слова), странные сочетания символов, случайные повторы, опечатки и фразы без достаточного контекста.
3. Попытаться восстановить смысл и проверить другие классы.
4. Присваивать UNKNOWN только если намерение действительно нельзя обоснованно определить.

Пример из предоставленного файла: `ываываыва` (UNKNOWN). Это **классификационный образец**, не доказательство, что фраза встречалась в поисковой базе.

## Контроль качества

Сохраняйте поле с исходной строкой без редактирования. Не выдавайте маски за данные поисковика. После выгрузки проверяйте язык, дубликаты, шум и пересекающиеся намерения.
