# Статус набора

Источники: `Processed/{CLASS}.csv`. Папка `Processing` была пустой, поэтому входные данные взяты из `Processed`.

- `Ready/queries_ru_7_classes.csv`: 300 оригинальных русскоязычных строк по каждому из семи классов, в формате `example/queries_example.csv`, но ещё без украинских и английских переводов.
- `Processing/selected_sources_for_3_languages.csv`: независимые RU-источники, помеченные `ru`, `uk`, `en` **по будущему назначению**, но пока не переведённые.
- Отбор выполнен правилами и эвристиками: для публикации окончательного обучающего набора нужна ревизия меток. Слово «реальный» означает наличие в пользовательской выгрузке, не доказательство ненулевой текущей частотности.
- В исходных CSV нет даты сбора, поэтому `collected_at` оставлена пустой, вместо подстановки выдуманной даты.
- В `UNKNOWN` недостаточно надёжных примеров для 900 оригиналов; бессмысленные последовательности нельзя осмысленно переводить.
