# Selection staging

Это **промежуточный** отбор источников из `Processed/{CLASS}.csv`. Переводы ещё не выполнены. После ручной проверки и качественного перевода источники следует разнести по трем языкам и сохранить результат в `Ready/` в формате `example/queries_example.csv`.

`collected_at` исходные CSV не содержат: дату сбора запросов нельзя выдумывать.

Доля нулевой точной частотности у класса UNKNOWN особенно велика: такие строки не являются надёжно подтверждёнными запросами реальных пользователей. Требуется отдельная валидация.

- INFORMATIONAL: 900/900 исходников, из 17591 строк (отобрано с ненулевой точной частотой 0).
- COMMERCIAL: 900/900 исходников, из 5604 строк (отобрано с ненулевой точной частотой 0).
- TRANSACTIONAL: 900/900 исходников, из 10432 строк (отобрано с ненулевой точной частотой 0).
- NAVIGATIONAL: 900/900 исходников, из 22590 строк (отобрано с ненулевой точной частотой 0).
- LOCAL: 900/900 исходников, из 3498 строк (отобрано с ненулевой точной частотой 0).
- MIXED: 900/900 исходников, из 2433 строк (отобрано с ненулевой точной частотой 0).
- UNKNOWN: 611/900 исходников, из 3614 строк (отобрано с ненулевой точной частотой 0).

Метки `target_assignment` задают назначение для будущего перевода, **не текущий язык текста** (здесь все строки из русской выгрузки).
