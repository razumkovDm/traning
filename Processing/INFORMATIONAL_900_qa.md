# INFORMATIONAL | 900 оригинальных русских запросов

- Источник: загруженный пользователем архив `для классификатора.zip` с выгрузками Букварикса сайтов `nkj.ru`, `lifehacker.ru`, `pochemuha.ru`.
- Полные исходные INFORMATIONAL-выгрузки: 934 705 + 347 478 + 8 564 = **1 290 747 строк**.
- В выборке: **900** исходных русскоязычных поисковых запросов, **900 уникальных нормализованных текстов**.
- Группы будущего назначения для Antigravity: `ru` = 300 оригиналов, `uk` = 300 исходных русских для перевода на украинский, `en` = 300 исходных русских для перевода на английский. **Ничего не переведено**.
- `collected_at` оставлен пустым: время сбора исходной выгрузки не известно.
- Частотность из столбца `!Частотность !Весь !мир` взята без изменения, не перепроверялась в поисковиках.
- Первичная фильтрация была консервативной: исключены очевидные запросы на покупку, бронирование, загрузку, переходы на сайты, большие тематические дубликаты и мусор; использована частотность и тематическое балансирование. Дополнительно сделана выборочная смысловая проверка.
- Это **подготовленный набор кандидатов**, а не гарантированная gold-разметка каждого примера: редкие спорные случаи требуют ручного аудита, прежде чем использовать датасет как эталонный.
