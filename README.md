# Search Query Training Dataset

Набор **реальных русскоязычных поисковых запросов** для тестирования поисковых систем, классификаторов намерений и сценариев поиска (например, pgF).

## Содержимое

| Путь | Назначение |
| --- | --- |
| `data/queries_300.txt` | 300 запросов, по одному в строке; UTF-8 |
| `data/queries_300.csv` | Те же 300 запросов с исходной частотностью; разделитель `;` |
| `data/queries_300.xlsx` | Таблица для просмотра/фильтрации в Excel |
| `templates/` | Поисковые маски Букварикса по 10 типам намерений |
| `templates/all_masks.txt` | Все маски одним списком |
| `source/README.md` | Происхождение и ограничения данных |

## Категории масок

1. Информационные вопросы
2. Сравнение и выбор товара/услуги
3. Инструкции и how-to
4. Проблемы и решения
5. Коммерческие (цена, условия, наличие)
6. Транзакционные (купить, заказать, записаться)
7. Навигационные
8. Локальные / геозависимые
9. Контент и медиа
10. Новости и актуальные запросы

## Происхождение

300 запросов отобраны из предоставленной пользователем выгрузки **Букварикса** (17 591 строка), а не сгенерированы языковой моделью. При отборе старались минимизировать смысловые повторы и обеспечить разнообразие тем. Частотность **взята из выгрузки**, не отражает текущую статистику поисковиков и отдельно не перепроверялась.

**Важно:** файлы `templates/*` содержат придуманные для поиска *маски*, а не реальные запросы пользователей. Эти категории не являются строгими взаимоисключающими классами, окончательный поисковый интент нужно проверять по результатам.

## Использование

- Для последовательного тестирования поиска: `data/queries_300.txt`.
- Для анализа частотности: `data/queries_300.csv` или `.xlsx`.
- Для расширения набора: подавайте маски из `templates/` в Букварикс и вручную фильтруйте полученные фразы.

В репозиторий не включена полная исходная выгрузка. Права на исходные базы и данные принадлежат соответствующим правообладателям; публикация не означает предоставление лицензии на сторонний набор.
